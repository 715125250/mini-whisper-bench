# 实测结果说明

- `real_t1.json`, `real_t4.json`: 本地 CPU 对同一英文样本的 1/4 推理线程顺序转写，每组先跑一次预热并记录三次。仅作小样本环境内对照。
- `stress_verified.json`: 带 2 个 C++ 任务 worker 和 2 项有界队列的版本，在真实 tiny 模型上的并发实测（8 并发、32 次请求）：16 个 200、16 个 429、无其他错误；worker 数 2、排队容量 2、准入峰值 4，结束后当前准入数回到 0。JSON 同时记录排队、音频准备、模型锁等待与处理时间。
- `environment.json`: 测试机器与运行时信息。
- `build.log`: 固定上游版本的第一次编译记录；`rebuild_threadpool.log` 是增加线程池后的增量编译记录。
- `model_conversion.log`: tiny 权重转换记录。

所有延迟受当前共享执行环境影响，数字不代表用户电脑或线上容量。压测中收到 429 是所测过载控制行为，不等于识别失败。每次重新运行请给新文件名，避免覆盖原始结果。
